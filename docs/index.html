Bots

An opponent for every level.

Each bot is a neural network trained by playing itself over hundreds of generations, and there are different bots for different difficulty settings. Pick your colour or leave it to chance.

New · Learns as you play

Shadow gets better every game.

Shadow starts just below Pragg and studies every game you finish against it. Beat it with a line and that line won't work twice: it never loses the same way again, and it repeats what won. Everything it learns stays on your phone, so it grows with you.

Online

Share a code, start a game.

Create a room and send the code to a friend. They type it in and you're playing, wherever they are. No account to set up.
